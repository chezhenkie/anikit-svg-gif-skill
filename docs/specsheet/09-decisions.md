# 09-decisions

Status: living document. One row per question. Status is `open`, `decided` or `parked`. Lean is a recommendation, not a decision. A decided row cites the part that carries the rule.

| # | Question | Lean | Status | Decision |
|---|---|---|---|---|
| 1 | Frame flow: materialised frames or a deterministic frame source? | Stream through a sink, sample twice | decided | Streaming sink with a cheap palette pass, a two-slot pipeline, and delays derived from presentation times. Part 03. |
| 2 | Composition: reject stacked animations or support them? | Support, because reuse is the point | decided | Layers with a weight track, an explicit order and per-type composite rules. Part 07. |
| 3 | Easing ownership: outgoing or incoming key? | Outgoing, WAAPI and Lottie convention | decided | Outgoing. SMIL is shifted by one on import. Part 04. |
| 4 | Duplicate key times: reject, or allow a hold? | Allow only when the earlier key holds | decided | Allowed only as a hold; lookup takes the last key at or before the time. Part 04. |
| 5 | Repetition: inside the timeline or outside it? | Outside, as a time map | decided | Loop mode and rate live in `Timing`; play count lives in the frame plan. Part 04. |
| 6 | Mesh warp for raster keys: in the first version? | No | decided | Out of the first version; crossfade and affine cover the GIF cases. Part 06. |
| 7 | Package and binary naming | `anikit-` package prefix, binary `anikit` | decided | Packages `anikit-core`, `anikit-time`, `anikit-tween`, `anikit-render-text`, `anikit-render-raster`, `anikit-render-svg`, `anikit-cli`. One binary, `anikit` (`anikit.exe` on Windows), built by `anikit-cli`. Part 02. |
| 8 | Cargo features for optional routes | None; the crate split is the split | decided | No features. One binary carries every route, which is what the skill installs; features would add a build matrix for no user. The crate split is the optionality. Part 02. |
| 9 | Animated GIF or WebP as an image source | Expand every frame, route timing wins | decided | Every frame is decoded in source order and joins the sequence as a still, so `--hold` and `--transition` apply between consecutive frames and the source's own delays are ignored. Each frame takes the row 10 matte. The silent first-frame read of the frozen Python is gone. Parts 01 and 03. |
| 10 | Alpha policy on the way into GIF | Matte onto `--bg`, no semi-transparent output | decided | Alpha is multiplied into `--bg` before the palette, so every frame is opaque. There is no 1-bit threshold and no transparent output, because GIF cannot carry partial alpha and a threshold would fringe soft edges. Row 9 applies the same matte to every frame of an animated source. Part 01. |
| 11 | Font asset for the text route | One embedded face, override by flag | decided | One embedded face: DejaVu Sans Mono regular, version 2.37, about 340 KB, committed beside `anikit-render-text` with its licence notice and loaded from the binary. `--font` or `ANIM_GIF_FONT` overrides it and there is no system search. It covers Basic Latin, Box Drawing and Block Elements in full, which is the glyph set ASCII art uses, and its licence permits redistribution. Bold is not drawn. Tests render with the embedded face, so fixture hashes do not depend on the machine. Parts 01 and 02. |
| 12 | Route order and Python deletion | Text, images, vector; delete each after its tests pass, core last | decided | Text, then images, then vector. Each Python file is deleted in the change that makes its Rust route pass the fixture and the structural checks; `gifkit.py` goes last. The text route landed first in this order. All three files, `gifkit.py`, `render_frames.cjs` and `tools/check.py` are deleted at 0.2.0. Part 08. |
| 13 | When the tween crate is built | After the Rust workspace exists | decided | It depends on `time` and `core` types, so it cannot be built before them. Parts 04 to 07 are its specification. |
| 14 | Repository name and release tags | `anikit-svg-gif-skill`; lightweight `vX.Y.Z` tags, existing tags kept | decided | The GitHub repository was renamed from `animated-gif-skill`, which keeps redirects. Tags `v0.1.0`, `v0.1.1` and `python-freeze` remain. The installed skill folder stays `animated-gif` because the folder name must match `SKILL.md`. |
| 15 | Alpine and musl build | Static `x86_64-unknown-linux-musl` binary; distribution Chromium for the vector route | decided | The text and images routes build as one static binary that runs on Alpine, glibc distributions and scratch containers. The vector route cannot use the Playwright browser there, because it is built against glibc; it uses the distribution `chromium` package instead. Alpine ships no fonts, which the embedded text face covers (row 11). |
| 16 | Motion vocabulary for weight and follow-through | Ballistic and arc segments, chains as layers, rest thresholds on springs | decided | A ballistic segment owns an absolute value and compiles into flights and contact holds; an arc is a quadratic bend on an eased move; a chain is a layer binding with a delay, not a segment. Springs gain `rest_delta` and `rest_speed` fields. Smear and blur stay renderer work, and squash is a deform track rather than a segment. Part 10. |
| 17 | GIF encoder: our own or a crate | Our own encoder in `anikit-core` | decided | The encoder is about 300 lines of LZW plus block writing, keeps the dependency list empty, and gives direct control of disposal and delta rectangles. The `gif` crate is a dev-dependency only, so the round-trip test decodes with an independent implementation. |
| 18 | Image decoding and EXIF | The `image` and `kamadak-exif` crates in `anikit-render-raster` | decided | `image` decodes png, jpeg, gif, webp, bmp and tiff; `kamadak-exif` reads orientation. Both are pure Rust and link into the static binary on every target. Decoders are a large correctness surface and not where this port should spend its risk. `time` stays dependency-free, and the renderer carries them; `core` adds only `png` for APNG output (row 22). Part 02. |
| 19 | How the vector route drives the browser | One CDP session over a WebSocket, no Node | decided | The port launches an installed Chromium with `--remote-debugging-port=0` and an empty profile, reads `DevToolsActivePort`, and drives one page target with the Chrome DevTools Protocol over a WebSocket. `tungstenite` carries the socket and `serde_json` the messages; a protocol implementation is not where this port spends its risk. The page loads once: animations are paused, each frame is seeked with `Animation.currentTime` and `SVGSVGElement.setCurrentTime`, and `Page.captureScreenshot` returns a PNG that the `image` crate decodes. The browser is killed and its profile removed when the route ends or fails. Repeated headless launches with `--virtual-time-budget` were measured to leave CSS and SMIL animations at their first frame in Chromium 146, so that shape cannot produce frames. The Python route, `render_frames.cjs` and the Playwright dependency are deleted together under part 08. Parts 02 and 08. |
| 20 | How the skill gets its binary | Release assets, no download or build at run time | decided | Each release carries the built binaries for the targets in part 02.5 as GitHub release assets, built by the GitHub Actions release workflow on the tag. The skill invokes one local binary and never downloads, unpacks or builds anything while making a GIF. A host without a matching asset is reported as an unsupported platform rather than worked around with a compiler or a package manager. The only runtime requirement outside the binary stays the browser of row 19, and only for the vector, tween and import routes. Part 02. |
| 21 | How the tween route draws a JSON timeline | Browser capture of SVG element state, one page, no new crate | decided | `anikit-render-svg` gains a second entry point. One SVG is loaded once, every animation clock is paused, each target element is wrapped in an empty `g`, and each frame writes the sampled transform, opacity, fill, stroke and stroke width before one screenshot. Those five kinds are what the implemented crate can show; path, raster, grid, spatial masks and alpha-only colour stay with their open gaps in parts 06 and 07 until a route needs them. The browser requirement of row 19 extends to this route. Part 11. |
| 22 | APNG writer: own chunks, or the `png` crate | The `png` crate for compression, our chunks for the animation | decided | `anikit-core` gains `png` 0.18 for RGB8 frame deflate; it is the only dependency core carries. The writer emits the signature, `IHDR`, `acTL`, `fcTL`, `IDAT`/`fdAT` and `IEND` itself, reserves the frame count, streams every frame, then patches the count and its checksum at finish and re-reads every chunk before the rename. Truecolor, no palette or dither, full-canvas frames, delays in hundredths of a second, and the same merge and 10 ms grid as GIF. Part 12. |
| 23 | SVG export from the tween route | CSS keyframes sampled from the prepared plan, no browser | decided | The tween route writes `.svg` by sampling its prepared plan at the renderer's presentation times and emitting one `@keyframes` rule per property into a style block before the closing `</svg>`. The last sample holds and the restart is the seam; `cycle` and `pingpong` are infinite, `once` is forwards; a transform track replaces the element's authored transform. The result is read back byte for byte and renamed. No frame-based route may write SVG. Parts 11 and 12. |
| 24 | How frames and timing leave and re-enter the pipeline | Extract to numbered PNGs and a JSON manifest; rebuild through `images --timing` | decided | `anikit extract` reads a GIF with the `image` decoder and an APNG with the `png` decoder, writes full-canvas RGB8 PNGs as `frame-0001.png` into a temp folder, and records the source size, loop count and per-frame delays in `manifest.json`. The folder is read back and renamed. `images --timing manifest.json` holds every still for its recorded delay at cumulative presentation times, with no fps grid and no transition; a missing `--width`, `--height` or `--loop` takes the manifest value. Part 13. |
| 25 | How an animated SVG becomes a timeline | Sample the five properties in one browser page at the renderer's frame times | decided | `anikit import` loads the drawing through the vector route's page, pauses every clock, samples transform, opacity, fill, stroke and stroke width at the tween route's frame times, and writes the canonical JSON with linear segments and a final hold at the loop end. CSS and SMIL are both covered because the browser resolves them. A changing colour must be opaque, a non-zero CSS transform origin is refused, and properties outside the five are skipped. The scene is exact at its own fps. Part 14. |
| 26 | Does a wrapped target keep its own animation, paused, or lose it? | Lose it; the timeline is the only motion | decided | A paused animation still contributes its value, and an imported scene writes the same property on the wrapper, so the motion would apply twice. The captured page sets `animation` and `transition` to `none` on every target before it loads, and the setup cancels any remaining animation object and removes SMIL animation children. Static attributes stay. Part 11. |
| 27 | A path pair whose command counts differ: fail or resample? | Resample by arc length, report the mode | decided | A pair that differs only in curve counts takes flubber's correspondence fallback: each subpath pair is sampled by arc length to a common point count, a closed ring searches every start offset, and the whole path reverses or not as one. A subpath count or closed-flag mismatch still fails. Prepare reports `PathFidelity::Resampled { points }`; the exact cubic mode is unchanged. Part 06. |

## Notes

- Rows 1 to 8 and 13 to 27 are settled by the research in docs/research/ and by the direction already agreed for the port. They are recorded here so a later change has to reopen them explicitly.
- Row 9 changes behaviour: the frozen Python reads frame 1 of an animated source without a message, and the fixture covers the expanded case.
- Row 10 applies to every frame that row 9 expands, not only the first.
- Row 11 drops the system font search, so the default glyphs differ from the frozen Python on every platform. Text fixtures compare structure and timing, not pixels.
