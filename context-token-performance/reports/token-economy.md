# Token economy

Every session pays a fixed context cost before work starts: the system prompt, project instructions, skills index and tool list. The baseline run measures it. Context token cost is the heaviest call of a run: input plus cache read plus cache write, in tokens. Overhead is that number minus the fixed cost, the context the task itself added. Time runs from session start to the last message. The product column links the finished animation, kept in the same folder.

## Method

The figures are the provider's own counters, read from `session_message.data` in the OpenCode database in read-only mode. The window size is not recorded in the local configuration, so the report prints tokens, not a share. Only valid runs are listed; draft runs and every prompt stay in `test-tools/sessions.csv`.

Generated by `test-tools/report.py` from `test-tools/sessions.csv`.
